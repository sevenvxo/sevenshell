# sevenshell

A desktop shell for [sevenwm](https://github.com/sevenvxo/sevenwm), built with Rust and GTK4.

> **Note:** sevenshell is currently in early development.

## Features

- Desktop bar
- Application launcher
- Window switcher
- Notifications
- Volume and brightness OSD
- Lock screen
- Login and greeter
- Keybinding viewer
- Desktop minimap
- sevenwm IPC integration
- Configurable through TOML

## Installation

### Arch Linux

```bash
git clone https://github.com/sevenvxo/sevenshell
cd sevenshell
./install.sh
